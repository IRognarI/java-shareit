# ShareIt

## Описание проекта

ShareIt — это бэкенд-приложение для шеринга (совместного использования) вещей. Сервис позволяет пользователям делиться своими предметами, брать в аренду вещи других людей, а также оставлять запросы на нужные предметы.

Приложение реализовано с использованием **микросервисной архитектуры** и состоит из двух основных модулей:
- **Gateway** — для обработки входящих запросов и валидации данных
- **Server** — для реализации основной бизнес-логики

## 🛠 Технологический стек

- **Spring Data JPA**
- **Maven**

### Тестирование:

- **Mockito**
- **Spring Boot Test**

### Другие технологии:

- **REST API**
- **Lombok**

## 🏗 Архитектура проекта

Проект состоит из двух основных модулей:

### 1. Gateway Service
- Обработка HTTP-запросов
- Валидация входящих данных
- Маршрутизация запросов к server-модулю
- Обработка ошибок и исключений

### 2. Server Service
- Реализация бизнес-логики
- Работа с базой данных
- Валидация бизнес-правил
- Обработка транзакций

## 📋 Основные функции

### Управление пользователями:
- Создание и обновление пользователей
- Просмотр всех пользователей
- Поиск пользователя по ID

### Управление вещами (Items):
- Добавление новых вещей
- Редактирование и удаление вещей
- Поиск вещей по названию и описанию
- Просмотр всех вещей пользователя

### Бронирование (Bookings):
- Создание бронирований
- Подтверждение/отклонение бронирований владельцем
- Просмотр истории бронирований
- Получение информации о текущих и будущих бронированиях

### Запросы на вещи (Item Requests):
- Создание запросов на нужные вещи
- Просмотр всех запросов пользователя
- Просмотр запросов других пользователей
- Поиск запросов по тексту

### Комментарии (Comments):
- Добавление комментариев к вещам
- Просмотр комментариев к конкретной вещи
